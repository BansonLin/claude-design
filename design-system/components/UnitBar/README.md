# UnitBar

戶型與戶數條：每一戶畫成一格，依戶型分組，下面寫戶型名與戶數。讓業主一眼看到產品組成。

- 每格 1.05rem × 1.6rem、`navy-ink` 88% 不透明、間距 3px、圓角 1px；戶型名用宋體 0.9375rem，戶數 0.75rem `navy-ink-2`。
- 上方用 `mini-h` 寫總數與核對結果（「合計 27 戶，與建照一致」）；格數必須等於建照戶數。
- 640px 以下格子縮成 0.85rem × 1.35rem，最大的一組獨佔一行。
- 只用在深藍案例區（外層 `.sec-case`）。
- 使用端提供：戶型名稱與每型戶數（每戶一個 `<i>`）。

靜態呈現：標記與 class 取自來源頁面，樣式來自 `components/bundle.css`。
