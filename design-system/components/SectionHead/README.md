# SectionHead

每個主要區塊的開頭：左邊眉標＋大標，右邊一段導言，上緣是一條 1px `ink` 實線。

- 兩欄 6:6，底部對齊；860px 以下改單欄。
- 大標用 `heading-1`（宋體 600，clamp 1.9–3.25rem），導言用 `body`、`ink-2`、寬度上限 36em。
- 導言寫「這一段要證明什麼」，一到兩句，最後幾個字用 `.nw` 包住避免孤字。
- 與下方內容的距離 clamp(2.5rem, 5vw, 4.5rem)。
- 使用端提供：編號、英文眉標、中文大標、導言。

靜態呈現：標記與 class 取自來源頁面，樣式來自 `components/bundle.css`。
