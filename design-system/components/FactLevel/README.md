# FactLevel

事實等級徽章：每條事實標明來源等級，A 建照／B 業主確認／C 估算提案／X 外部查證。

- 1.5rem 見方、1px 外框、`r-tag`、0.75rem 600 字；以 `<abbr class="lv" title="A 建照">` 標記，滑鼠停留顯示全名。
- 只要畫面上出現規格或數字，就在旁邊放等級；同一區塊底部放一次圖例 `.lv-legend`。
- 用在深藍案例區時，外框與字都是 `navy-ink-2`。
- C 級（估算）的數字對外引用時，必須加「（估算）」字樣。
- 使用端提供：等級字母與完整說明。

靜態呈現：標記與 class 取自來源頁面，樣式來自 `components/bundle.css`。
