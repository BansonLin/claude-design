# ProcessRail

九個階段的總覽軌道：每個階段一個 44px 圓形代碼（P0–P8），下方是名稱與決策關卡（G0–G8）。

- 代碼圓用宋體 600、1px `ink` 外框、`r-round`；hover 反白成墨色實心。
- 關卡用旋轉 45° 的 `brass` 小方塊加 `brass-ink` 代碼，象徵「這裡要業主拍板」。
- 桌機一列九格，中間一條 `rule-strong` 細線串起；1024px 以下改五欄、640px 以下三欄並拿掉細線。
- 每格連到對應的 Phase 區塊。
- 使用端提供：階段代碼、名稱、關卡代碼與錨點。

靜態呈現：標記與 class 取自來源頁面，樣式來自 `components/bundle.css`。
