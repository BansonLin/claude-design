# MaterialCard

交付物資料庫的卡片：16:9 縮圖、分類與階段、標題、說明、規格（頁數／大小／格式）、動作或限制說明。

- 上緣 1px `ink` 實線；縮圖底 `paper-3`、圓角 `r-tag`；沒有圖時用 `.ph-deck` 佔位（宋體編號＋標題＋階段）。
- 狀態標籤放在縮圖右上角（Tag），標題才不會因標籤換行而高低不齊。
- `mat-meta` 用 tabular-nums；不提供下載的檔案改放 `.restricted` 說明，不要讓按鈕消失而沒有交代。
- 網格 `auto-fill minmax(15.5rem, 1fr)`；手機版改為左側 96px 小縮圖的列表。
- 使用端提供：縮圖或佔位資訊、分類、階段、標題、說明、規格、連結或限制說明。

靜態呈現：標記與 class 取自來源頁面，樣式來自 `components/bundle.css`。
