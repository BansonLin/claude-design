# ServiceCard

服務模組卡：代碼（M1–M9）、對應階段、名稱，以及「做什麼／交付什麼／業主得到什麼」三段。

- 卡片排成無間距的格線（1px `rule` 共用邊），底色 `paper`，整區底色 `paper-2`；桌機三欄、平板兩欄、手機一欄。
- 代碼用宋體 600、`brass-ink`；三段小標用 `label`（字距 .16em、`brass-ink`），內文 `body-s`、`ink-2`。
- 「業主得到什麼」寫結果，不寫形容詞；卡片底部用 SourceChip 列出本案交付物。
- 使用端提供：代碼、對應階段、名稱、三段內容、交付物連結。

靜態呈現：標記與 class 取自來源頁面，樣式來自 `components/bundle.css`。
