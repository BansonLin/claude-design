# VerifyMethod

物料核實區塊：左欄核實方法（自動編號），右欄核實角度與結果框。用來說明「出版前怎麼逐頁查」。

- 兩欄 7:5；1024px 以下改單欄。方法清單用 CSS counter 產生兩位數編號（宋體、`brass-light`），標題 1.0625rem，說明 0.9375rem `navy-ink-2`，條目之間 1px `navy-rule`。
- 右欄先放 AngleTags，再放結果框 `.results`：`navy-deep` 底、1px `brass-light` 虛線框、圓角 `r`；數字用宋體 1.75rem `navy-ink`，四欄一列，分級列三欄。
- 結果框只放在內部完整版（外層 `data-sensitive`）；對外版改放 `.results-public` 一句話（「核實結果與修正清單於業主會議中說明。」），右欄改單欄。
- 方法要寫查證規則本身（以建照為準、至少兩道確認才保留），不要寫成形容詞。
- 預覽中的數字以「—」佔位：核實數字屬於案件內部資料，不放進設計系統。
- 使用端提供：方法條目、角度清單、內部版的核實數字與分級、對外版的一句說明。

靜態呈現：標記與 class 取自來源頁面，樣式來自 `components/bundle.css`。
