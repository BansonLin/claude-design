# Journey

決策歷程卡：一個決策從業主輸入、璞域提案、業主定案到回寫的時間線。

- `navy-deep` 底、圓角 `r`；標題 `heading-3`，摘要一行 `brass-light`。
- 每一步左欄 5.25rem 放階段標籤（0.75rem、字距 .1em、`navy-ink-2`）；「業主定案」那一步標籤改 `brass-light` 粗體、內文 500，讓定案最先被看到。
- 被取代的提案照實寫出（「第一推薦為……」），不刪除歷史；回寫步驟寫清楚舊用語怎麼被攔下。
- 兩張並排；860px 以下單欄。
- 使用端提供：決策名稱、一行摘要、3–4 個步驟（類型＋內容），選用的圖片。

靜態呈現：標記與 class 取自來源頁面，樣式來自 `components/bundle.css`。
