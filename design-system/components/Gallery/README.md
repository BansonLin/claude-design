# Gallery

案例圖庫：分組篩選 chip、所選分組的說明，以及偶數欄的圖片網格。點圖開啟 Lightbox。

- 網格固定偶數欄（桌機 6、1180px 以下 4、640px 以下 2），橫幅圖才能跨兩欄而不留空格。
- 一般圖 4:3 `cover`；寬度超過高度兩倍的橫幅（`is-wide`）跨兩欄、8:3、`contain` 不裁切；直式圖（`is-tall`）改 `contain`。
- 縮圖底 `navy-deep`、圓角 `r-tag`；hover 放大 1.035 倍。圖說兩行：標題 `navy-ink`、分組 0.75rem `navy-ink-2`。
- 選了分組後，`.g-notes` 顯示該組的示意聲明（「3D 示意……以建照圖說為準」）；先顯示 8 張，其餘收在「顯示全部 N 張」按鈕後面。
- 只用在深藍案例區（外層 `.sec-case`）。
- 使用端提供：分組與張數、每組聲明、每張圖的縮圖、原圖、標題、分組、替代文字（含示意說明）。

靜態呈現：標記與 class 取自來源頁面，樣式來自 `components/bundle.css`；圖片是 CaseImagery 素材群組的上傳檔。
