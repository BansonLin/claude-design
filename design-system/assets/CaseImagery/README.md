# CaseImagery

- `ext01.jpg`、`ext03.jpg` — 外觀透視（560px 寬，4:3 上下）。3D 示意；車輛為情境示意，停車規劃以建照圖說為準。
- `ext02-wide.jpg` — 臨路街景全景（800 × 218），橫幅，在圖庫中跨兩欄。同上聲明。
- `int-1f-l01.jpg`、`int-1f-l04.jpg`、`int-3f-f01.jpg` — A1 標準戶室內（560 × 315）。室內設計示意；家具與設備是否交屋以契約為準。
- `int-2f-r04.jpg` — 室內直式近景（560 × 700），在圖庫中以 `is-tall`（contain）呈現。同上聲明。
- `kv-v1.jpg`～`kv-v8.jpg` — 業主提供的 8 色主視覺稿縮圖（320 × 135）：玫瑰系 v1／v3／v5／v7、水仙系 v2／v4／v6／v8。v7 為原推薦，v2 為定案底色參考。品牌階段的比較稿，不是定案主視覺。

使用規則：每次出現都要帶示意聲明；圖片屬於業主案件，用在案例以外的地方前，先確認業主授權範圍。
