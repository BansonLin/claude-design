璞域品牌策略的視覺系統，用在給建設公司看的企劃服務說明、提案與案例文件。整體像一份排過版的提案書：米紙底、墨色字、黃銅點綴，深藍只留給案例。標題用宋體、內文用黑體，以細線分層，不用陰影。

## 內容原則

- **語言**：繁體中文（台灣用語），文件標 `lang="zh-Hant-TW"`。英文只用在區塊眉標（大寫，例如「CHALLENGES」「CASE STUDY」）與專有名詞。
- **語氣**：陳述事實、短句、具體數字，不用形容詞撐場面。例：「9 個服務模組，可整案或分段委託」「定價依據來自壯圍、五結與宜蘭市 24 個月的實價登錄成交」。
- **人稱**：自稱「我們」或「璞域」；對方稱「業主」或「建設公司」。
- **每個主張都有出處**：數字旁放 SourceChip，規格旁放 FactLevel（A 建照／B 業主確認／C 估算提案／X 外部查證）。C 級數字對外引用時加「（估算）」。
- **固定句型**：難題寫成「痛點 → 本案經驗 → 我們的做法」；服務寫成「做什麼 → 交付什麼 → 業主得到什麼」。「本案經驗」只寫實際發生過的事。
- **代碼體系**：服務模組 M1–M9、流程階段 P0–P8、決策關卡 G0–G8。內文直接用代碼（「依 P0～P8 排出各階段」）。
- **不用**：驚嘆號、emoji、無法查證的最高級（最、第一、頂級）、會被認定不實的廣告用語。渲染圖一律標「3D 示意」，彩平標「平面示意」，並註明「實際以建照圖說與買賣契約為準」。
- **標點與數字**：全形「，。、：；（）」；並列與分隔用全形「／」「｜」；範圍用「–」或「～」。數字與單位之間空半形（「27 戶」「24 個月」），並用 `.nw` 包住，避免拆行；段落最後兩三個字也包 `.nw`，避免孤字。

## 視覺基礎

### 色彩

- 頁面底用 `paper`，交替區塊用 `paper-2`，佔位與縮圖底用 `paper-3`。
- 文字用 `ink`（標題、內文）、`ink-2`（導言、說明、清單）、`ink-3`（小標、圖說，只放在 `paper` 上）。
- 黃銅是唯一的強調色。`brass` 用在線條、焦點框和 24px 以上的編號；`brass-ink` 用在小字、代碼和大數字；`brass-soft` 是決策關卡的底。整頁的黃銅只出現在線條、小字與數字，不鋪大面積。
- 深藍 `navy` 只用在案例展示區（`.sec-case` 整段底色）。區內文字用 `navy-ink`／`navy-ink-2`，強調用 `brass-light`，分隔線用 `navy-rule`，次一層卡片用 `navy-deep`。不要把深藍當按鈕或連結色。
- 墨色反白（`ink` 底、`paper` 字）只給主按鈕、CrossPanel 和頁尾。
- 三個主題：**Light**（預設）、**Dark**（僅螢幕）、**Print**（白底黑字，深藍區轉白，黃銅保留）。輸出 PDF 時用 Print。
- 已知對比缺口，照來源原值保留：淺色主題下 `ink-3` 在 `paper-2`／`paper-3` 上不足 4.5:1，這兩種底上改用 `ink-2`。`rule-strong` 當控制項框線約 1.9:1，所以選取狀態一律用實心反白表達。

### 字體

- 兩個字族。`serif`（Noto Serif TC 500/600/700）用在標題、數字、代碼、品牌字；`sans`（Noto Sans TC 400/500/700）用在內文與標籤。兩者都從 Google Fonts 載入，`components/bundle.css` 第一行已經 `@import`。
- 標題一律 600。行高：標題 1.35、內文 1.75、導言 1.85。
- 大標字級用 `clamp()` 隨視窗縮放，各樣式的說明有完整範圍：`display-hero`、`display-case`、`heading-1`、`heading-2`、`numeral`、`lead`。
- 小標靠字距、不靠加粗：`eyebrow` .2em、`mini-h` .18em、`label` .16em。
- 中文標題只在標點處換行（`word-break: keep-all`、`text-wrap: balance`）。

### 版面與間距

- 內容最寬 `maxw`（1280px），左右邊距 `gutter`（16–56px），主要區塊上下距 `sec-pad`。導覽列高度 `nav-h`。
- 版面用不對稱兩欄（7:5、6:6、5:7）和共用邊的格線卡片，不用浮起的卡片。
- 間距用 `space-1` 到 `space-9`（0.25–2.25rem），最常用的是 `space-4`（1rem）。
- 斷點：1180、1024、860、640px。640px 以下篩選列改為橫向捲動，交付物卡片改為小縮圖列表。

### 線條、圓角、陰影

- 用 1px 細線分層。區塊開頭用 `ink` 實線，區塊內用 `rule`，控制項外框用 `rule-strong`，深藍區用 `navy-rule`。需要強調的上緣用 2px `brass`。虛線只出現在「本案交付物」分隔、內部提醒條和 `tag-int`。
- 預設圓角是 `r`（3px）；標籤、徽章和圖片用 `r-tag`（2px）；只有篩選類控制項用 `r-pill`；流程圓用 `r-round`。
- 陰影只有兩處：展開的選單用 `shadow-menu`，燈箱大圖用 `shadow-lightbox`。其他地方都不用陰影。

### 圖像

- 照片與渲染圖用 `object-fit: cover` 填滿，圓角 `r-tag`。常用比例：縮圖 16:9、圖庫 4:3、主視覺橫幅 8:3（用 `contain`，不裁切）。
- 圖說用 `caption`，前面加一條 1.5rem 的 `brass` 細線；渲染圖的圖說一定要寫「3D 示意」。
- 圖庫 hover 時圖片放大 1.035 倍（0.5s、`cubic-bezier(.2,.7,.2,1)`）。

### 動態與狀態

- 轉場 0.15–0.2s，只動底色、框線色和箭頭位移（按鈕 4px、tile 3px）。設定 `prefers-reduced-motion` 時全部關閉。
- 鍵盤焦點：2px `brass` 實線 outline，外推 3px；深藍區改用 `brass-light`。兩者在各自的底色上都達到 3:1 以上。
- 選取與目前項目：chip 和分段切換用墨色實心反白；導覽目前段落用 2px `brass` 底線；流程圓 hover 反白。

## 標誌與圖示

- 原始碼裡沒有璞域的標誌檔。品牌一律用 `brand` 字樣呈現：「璞域品牌策略」，宋體 600、字距 .08em，後接副標「建案企劃服務」。取得正式標誌檔後，再補進 Logos 資產群組。
- 沒有圖示庫，只用文字符號：行動箭頭「→」、翻頁「‹ ›」，以及決策關卡的 45° 小方塊（CSS 繪製）。不用 emoji。

## 內部版與對外版

- 同一份內容輸出兩個檔：內部完整版與對外版。短詞用 `.sx` 標示（`sens` 淡底），整句用 `.sx-long`（點狀底線），整塊內部內容加 `data-sensitive`，對外版會移除或改成概稱（「宜蘭在地業主」）。
- 對外版不放定價、預算、業主名稱、內部檢討與核實細節。要寄出的檔案另外產生，不要只靠瀏覽器隱藏。
- 對外檔在導覽列放 `pub-badge`「對外版」；內部檔放 ModeNote 提醒條。
- 對外內容只留官網，不寫死服務據點。

## 元件

元件就是樣式表裡的 class：頁面載入 `components/bundle.css`，再依各元件 README 的標記寫 HTML。這套系統沒有 JavaScript 元件。

- **Actions**：Button、Chip、SourceChip
- **Navigation**：NavBar、ProcessRail
- **Labels**：Eyebrow、Tag、FactLevel
- **Layout**：SectionHead、Facts、CrossPanel、Contact、Footer
- **Content**：ProblemItem、ServiceCard、Phase、MaterialCard、NumberedList、ModeNote
- **Case**（深藍案例區，外層要有 `.sec-case`）：CaseSpecs、StatTiles、Journey

## 案件品牌

- 每個建案自己的品牌（例如中道·森活 III 的深藍底＋白玫瑰）屬於業主，記錄在該案的 `case.yaml`，不併入這套系統。在璞域的文件裡引用案例時，用本系統的 `navy` 案例區承接，不改成案件色票。

## 未同步項目

- 字型檔沒有存進系統：兩個字族都由 Google Fonts 託管。
- 標誌：來源中沒有。
- 元件為靜態呈現：來源是 Python 產生的靜態頁面，沒有元件庫，所以沒有建立 JS bundle。以下元件尚未收錄：燈箱、圖庫格線、簡報模式控制列、戶型戶數條、核實方法與結果、主視覺比較條、核實角度標籤。
- 來源中的字面值（非 CSS 變數），依出現頻率命名後收錄：`space-*`、`sec-pad`、`r-tag`、`r-pill`、`r-round`、兩個陰影。
- 寫死的色值保留在 bundle.css：深色主題的頁尾底 #0D0C0A、深色主按鈕字 #151411，以及燈箱用的 #EEE 與半透明白。
