# claude-design

璞域品牌策略的設計系統原始檔。

- `design-system/`：從 `BansonLin/Pure-space-Branding`（fcbe10d）的服務說明網頁 CSS 萃取。
  - `README.md`：品牌手冊（內容原則、色彩、字體、版面、元件用法）
  - `tokens.json`：37 個 token，含淺色、深色、列印三套主題，另有 19 個字型樣式
  - `components/bundle.css`：元件樣式表（來源 CSS，色值改由 token 提供）
  - `components/<元件>/`：22 個元件的用法說明與靜態預覽，以及封面
- 線上版：Claude 設計系統 artifact「璞域品牌策略」。
